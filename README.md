# Hospital Management System

A simple hospital management system built with HTML, CSS, and JavaScript.

## Features

- Patient registration and management
- Doctor directory with specialties
- Appointment scheduling
- Department overview
- Billing and revenue summary
- Local storage persistence for demo data

## Run locally

Open `index.html` in a browser.

For a local web server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Project structure

- `index.html` – app layout
- `styles.css` – styling
- `script.js` – app logic and data management

## Notes

This app is intentionally lightweight and is designed as a demo project for learning and extension.
